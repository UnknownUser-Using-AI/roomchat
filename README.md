# roomchat

실시간 공개 채팅방입니다. 지정된 **「슬랩배틀 라이벌 입양 피기」** 방을 맨 위에 고정하고, 누구나 게스트 또는 닉네임·비밀번호 계정으로 참여할 수 있습니다. 정적 웹 파일은 GitHub Pages에, 방·메시지·계정 프로필은 Supabase에 저장됩니다.

## 기능

- **게스트**: 닉네임을 바꾸고 방을 만들 수 있습니다. 닉네임은 이 브라우저 탭의 세션에서만 유지되며 계정 프로필로 저장되지 않습니다. 탭을 닫으면 다시 입력해야 합니다.
- **계정**: 이메일 입력 없이 닉네임과 비밀번호로 가입·로그인합니다. 비밀번호는 Supabase Auth가 해시하여 보관하고, 사이트는 실제 이메일 주소를 요청하거나 저장하지 않습니다. 계정 닉네임은 보존되고 변경할 수 있습니다.
- **닉네임 보호**: 중복되거나 제어문자·링크·부적절한 표현 등 사용이 제한된 이름은 `크리스탈 시청자` 이름으로 자동 변경합니다. 해당 이름도 사용 중이면 `크리스탈 시청자 2`처럼 빈 이름을 선택합니다.
- **인증 관리자**: `[인증됨] 천사` 및 `[인증됨] 크리스탈` 두 닉네임은 각자의 일회용 초대코드로만 만들 수 있습니다. 초대코드는 계정 생성 즉시 폐기되며, 이 두 계정만 서버에서 관리자 권한과 굵은 무지갯빛 닉네임 표시를 받습니다. 관리자 인증 닉네임은 변경할 수 없습니다.
- **방 운영**: 게스트와 계정 모두 공개 방을 만들 수 있습니다. 방을 만든 사람은 그 방의 운영자로서 참가자를 내보낼 수 있고, 관리자는 어느 방에서나 이를 수행할 수 있습니다.
- **관리자 도구**: 관리자는 활동 중인 이상한 닉네임을 `크리스탈 시청자`로 정리하고, 메시지 및 고정 기본방을 제외한 방과 그 대화·첨부 이미지를 삭제할 수 있습니다.
- **실시간 채팅**: Supabase Realtime으로 메시지와 참여자 수를 갱신하고, 최근 100개 메시지를 불러옵니다. 이미지 붙여넣기·파일 첨부는 JPEG/PNG/WebP/GIF/AVIF, 최대 8MB를 지원합니다.

## 보안 및 공개 범위

모든 방, 메시지, 프로필 닉네임 및 공유 이미지는 공개 채팅용 데이터입니다. 비밀번호는 메시지 테이블에 저장하지 않으며, 인증된 역할·닉네임·방장 토큰·게스트 세션 토큰은 브라우저에서 임의로 부여할 수 없습니다. DB 쓰기는 권한을 검사하는 RPC를 거치며 일반 브라우저 클라이언트에는 Supabase `service_role` 키가 들어 있지 않습니다.

닉네임 제한은 제어문자, URL 형식, 과도한 기호 및 기본 부적절 단어 목록을 이용한 자동 필터입니다. 자동 판정이 놓친 방·닉네임·대화는 관리자가 직접 정리할 수 있습니다. 고정 기본방은 일반 운영 중 실수로 사라지지 않도록 관리자 삭제 대상에서 제외했습니다.

## Supabase 배포 순서

신규 SQL 변경은 두 단계로 분리되어 있습니다. 기존 사이트와 이용 기록을 유지하며 기능을 추가하고, 새 사이트가 연결된 뒤 기존의 익명 직접 쓰기 권한만 제거합니다.

1. `feature_migration.sql`을 Supabase 프로젝트 `losuyalyjcurntylbwgy`에 적용합니다. 기존 방과 메시지는 삭제·변경하지 않고, 지정 고정방 및 프로필·권한·세션 함수만 추가합니다.
2. `supabase/functions/roomchat-auth/index.ts`의 `roomchat-auth` Edge Function을 `verify_jwt=false`로 배포합니다. 이 함수는 누구나 호출할 수 있는 가입·로그인 창구지만, 비밀번호 인증과 일회용 관리자 코드를 서버에서 검증합니다. `service_role` 키는 Edge Function에서만 사용해야 합니다.
3. 저장소 루트의 `index.html`, `app.js`, `styles.css`를 GitHub Pages에 배포합니다.
4. 새 앱이 작동하는 것을 확인한 다음 `security_migration.sql`을 적용합니다. 방·메시지의 직접 INSERT 권한을 제거하고 지정된 서버 RPC만 쓰기 경로로 남깁니다.

`migration.sql`은 기존 기본 스키마입니다. 이미 적용된 운영 프로젝트에서 다시 실행할 필요는 없습니다. 웹의 공개 publishable key는 `config.js`에 두어도 되지만 `service_role` 키·비밀번호·일회용 관리자 초대코드는 공개 저장소에 올리지 마세요.

## GitHub Pages

현재 고정 주소는 <https://unknownuser-using-ai.github.io/roomchat/> 입니다. 모든 웹 파일은 저장소 루트에 있고, GitHub **Settings → Pages → Deploy from a branch → `main` → `/(root)`**로 배포합니다. 정적 사이트라 별도 빌드 명령은 없습니다.

## 알림

알림 권한은 사용자의 버튼 클릭으로 요청합니다. 이 탭이 열려 있고 Supabase Realtime 연결이 살아 있는 동안 새 메시지를 알립니다. 브라우저를 완전히 닫았을 때의 푸시 알림은 별도의 Web Push 서버·구독 설정이 필요합니다.
